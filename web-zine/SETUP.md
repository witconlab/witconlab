# 웹진 설치 안내서 (선생님용)

개인 구글(Gmail) 계정만 있으면 됩니다. 프로그램을 설치하거나 코딩할 필요는 없어요. 순서대로 따라 하세요. 처음이면 30분 정도 걸립니다.

**전체 그림**
- 학생이 쓰는 화면(웹 페이지)은 GitHub Pages로 공개합니다.
- 학생의 진과 사진은 선생님 구글 드라이브의 `웹진` 폴더에 저장됩니다. 저장을 맡는 작은 프로그램(Apps Script)이 `apps-script/Code.gs` 파일입니다.
- 두 가지를 이어 주는 주소 하나를 `web-zine/js/config.js`에 적어 주면 끝입니다.

---

## 1. 새 Apps Script 프로젝트 만들기

1. 크롬에서 구글에 로그인한 뒤 https://script.google.com 에 들어갑니다.
2. 왼쪽 위 **새 프로젝트**를 누릅니다.
3. 위쪽 "제목 없는 프로젝트"를 눌러 이름을 `웹진`으로 바꿉니다.
4. 가운데 코드 창에 `function myFunction() {}` 같은 글이 있으면 전부 지웁니다. (Ctrl+A → Delete, 맥은 Cmd+A)
5. 이 저장소의 `web-zine/apps-script/Code.gs` 파일을 열어 **내용 전체를 복사**해 코드 창에 붙여 넣습니다.
6. 디스크 모양 **저장** 버튼(또는 Ctrl+S)을 누릅니다.

(화면 캡처: 코드 창에 Code.gs를 붙여 넣은 모습)

## 2. `setup` 실행하고 권한 허용하기

1. 코드 창 위쪽의 함수 선택 칸(▶ 실행 옆)에서 `setup`을 고릅니다.
2. **실행**을 누릅니다.
3. "승인 필요" 창이 뜨면 **권한 검토** → 본인 구글 계정 선택.
4. "Google에서 확인하지 않은 앱" 화면이 나오면 정상입니다(내가 만든 프로그램이라서요). **고급** → **웹진(안전하지 않음)으로 이동** → **허용**을 누릅니다.
5. 아래 "실행 로그"에 **실행 완료**가 나오고 **설치 완료**가 보이며, 내 구글 드라이브에 `웹진` 폴더가 생기면 성공입니다.

(화면 캡처: 권한 허용 화면의 "고급" 위치)

## 3. 관리자 비밀번호 정하기

1. 왼쪽 메뉴의 톱니바퀴 **프로젝트 설정**을 누릅니다.
2. 맨 아래 **스크립트 속성** → **스크립트 속성 추가**.
3. 속성: `ADMIN_PASSWORD`, 값: 정한 비밀번호. **스크립트 속성 저장**을 누릅니다.

**비밀번호는 길게 만드세요.** 12글자 이상, 영문과 숫자를 섞고 다른 곳에서 쓰지 않는 것으로 합니다. 관리자 비밀번호를 5번 틀리면 10분 동안 관리자 로그인이 잠깁니다(학생 비밀번호와 같은 규칙). 잠기면 10분 기다렸다가 다시 들어가세요.

(화면 캡처: 스크립트 속성 추가 화면)

## 4. 웹 앱으로 배포하기

1. 오른쪽 위 파란 **배포** 버튼 → **새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설정:
   - 설명: `웹진`
   - **실행 계정: 나**
   - **액세스 권한: 모든 사용자**
4. **배포**를 누르고 권한을 다시 허용합니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 **복사**해 메모장에 붙여 둡니다.

"모든 사용자"로 해야 학생들이 구글 로그인 없이 쓸 수 있습니다. 주소를 아는 사람만 접속할 수 있고, 실제 데이터는 학생 이름과 비밀번호가 있어야 열립니다.

(화면 캡처: 배포 버튼 위치)
(화면 캡처: 웹 앱 설정과 URL 복사 화면)

## 5. 웹 주소를 `config.js`에 넣고 올리기

1. 저장소의 `web-zine/js/config.js` 파일을 엽니다. 이런 모양입니다.

   ```js
   export const API_URL = 'mock';
   ```

2. `'mock'` 자리에 방금 복사한 주소를 따옴표 안에 넣습니다.

   ```js
   export const API_URL = 'https://script.google.com/macros/s/여기에-내-주소/exec';
   ```

   > **중요:** `'mock'`은 연습용입니다. 그 브라우저 안에만 저장되고 다른 기기에서는 보이지 않으며, 선생님 드라이브에도 저장되지 않아요. **수업 전에 반드시 위 주소로 바꾸세요.**

3. 변경을 커밋하고 푸시합니다. (Claude Code를 쓰고 있다면 "config.js 바꾸고 푸시해줘"라고 요청해도 됩니다.)

### GitHub Pages로 공개하기

이 저장소(witconlab/witconlab)에서 GitHub Pages가 켜져 있다면, 푸시 후 몇 분 뒤 아래 주소로 열립니다.

- 학생 화면: https://witconlab.github.io/witconlab/web-zine/
- 선생님 화면: https://witconlab.github.io/witconlab/web-zine/admin.html

켜져 있지 않다면: GitHub 저장소 → **Settings** → **Pages** → Branch를 배포할 브랜치(예: `main`), 폴더 `/ (root)`로 선택 → Save. 배포가 끝나면 **Settings → Pages** 화면 위쪽에 실제 접속 주소가 나타납니다. 웹진 파일은 `web-zine` 폴더에 있으므로 주소 끝에 `/web-zine/`가 붙습니다. 웹진을 `main`에 합치기 전이라면 브랜치 선택에 `web-zine`이 보이는지 확인하세요.

(화면 캡처: GitHub Pages 설정 화면)

## 6. 나중에 `Code.gs`를 고쳤을 때 (주소 유지)

> 이 버전의 `Code.gs`는 학생 30명이 동시에 저장해도 서로 기다리지 않도록 바뀌었습니다. 예전 버전을 붙여 넣은 적이 있다면 새 `Code.gs` 전체로 바꿔 붙여 넣고 아래처럼 **새 버전**으로 배포하세요.

코드를 고쳐서 붙여 넣은 뒤, **새 배포를 만들면 주소가 바뀝니다.** 주소를 그대로 두려면:

1. **배포** → **배포 관리**.
2. 쓰고 있는 배포 옆 연필(수정) 아이콘.
3. 버전: **새 버전** 선택 → **배포**.

이렇게 하면 `config.js`는 그대로 두어도 됩니다.

## 학생 사진은 어디에 저장되나요?

- 드라이브의 `웹진/<학생 이름>/photos` 폴더에 사진이, `웹진/<학생 이름>/zine.json`에 진 내용이 저장됩니다. 스티커는 `웹진/stickers`에 있습니다.
- 사진은 공개되지 않습니다. 드라이브 폴더는 선생님만 볼 수 있고, 학생 화면은 로그인한 학생(또는 관리자)에게만 사진을 보여 줍니다. `웹진` 폴더를 다른 사람에게 공유하지 마세요.

## 백업하기

수업이 끝나면 한 번 백업해 두세요. 구글 드라이브에서 `웹진` 폴더를 오른쪽 클릭 → **다운로드**하면 zip 파일로 받아집니다. (폴더 이름이나 사진을 직접 옮기거나 지우면 진이 깨질 수 있으니 드라이브 안에서는 건드리지 마세요.)

## 학생에게 알려 줄 것

- **카카오톡 안에서 열지 말고 Safari(아이폰) 또는 Chrome(안드로이드)에서 여세요.** 카카오톡 안의 브라우저에서는 사진 올리기와 저장이 잘 안 될 수 있어요. 카톡으로 주소를 보냈다면, 링크를 길게 눌러 "Safari로 열기"(또는 오른쪽 아래 ⋯ → 다른 브라우저로 열기)를 고르게 하세요.
- 같은 이름이 이미 있으면 그 진으로 들어갑니다. 처음 들어오는데 "비밀번호가 맞지 않아요"가 나오면 이름 뒤에 숫자를 붙이게 하세요 (예: 김민지2).
- 기기를 여러 학생이 같이 쓰면, 편집기 위쪽의 이름 단추(또는 보기 화면의 **다른 이름으로 들어가기**)를 눌러 바꿔 들어가게 하세요.
- 화면 위에 빨간 **"연습 모드"** 띠가 보이면 아직 `config.js`가 `'mock'`인 상태입니다. 학생 작업이 그 기기에만 저장되니 바로 5단계를 확인하세요.

## 선생님 화면 쓰는 법 (admin.html)

- 관리자 비밀번호로 들어갑니다. 학생 표에서 채운 쪽, 마지막 수정, 완성 여부, 잠김 여부를 봅니다.
- **보기**: 학생의 e-book을 봅니다. **쪽 PDF**: 그 학생의 8쪽 PDF를 받습니다.
- **비밀번호 바꾸기**: 새 숫자 4자리를 입력하면 바뀌고, 화면에 한 번만 알려 줍니다. 학생에게 말해 주세요.
- **잠금 풀기**: 비밀번호를 여러 번 틀려 잠긴 학생을 바로 풀어 줍니다.
- 학생 앞 체크박스를 고르고 **A3 접기용 PDF**를 누르면 한 장에 한 명씩 인쇄·접기용 PDF가 나옵니다. "접는 선 표시"는 기본으로 켜져 있어요. 파일 이름은 `A3_날짜_N명.pdf`입니다.
- **A3 PDF는 한 번에 10명 이하로 나눠서 만드세요.** 한 번에 너무 많이 고르면 사진을 내려받고 그리는 데 오래 걸리고, 태블릿이나 오래된 컴퓨터에서는 메모리가 모자라 멈출 수 있어요.
- **스티커 추가**: PNG를 올리면 학생 편집기의 스티커 목록에 나타납니다.

## 30명 동시 사용 점검 (수업 전에 한 번)

컴퓨터에 Node.js(18 이상)가 있으면, 학생 30명이 한꺼번에 저장·사진 올리기를 하는 상황을 미리 흉내 내 볼 수 있어요. (Claude Code를 쓰고 있다면 "부하 점검 돌려줘"라고 요청해도 됩니다.)

```
node web-zine/tests/load-check.mjs https://script.google.com/macros/s/여기에-내-주소/exec
```

- 가짜 학생 `테스트01` ~ `테스트30`이 동시에 들어와서 저장 3번, 사진(약 200KB) 1장을 올립니다. 1~2분 걸립니다.
- 끝나면 성공/실패 수와 응답 시간(p50, p95)이 나옵니다. **"끝까지 성공한 학생: 30/30"** 이면 통과입니다. 실패가 있으면 표 아래 "실패 이유"를 확인하세요. (재시도 숫자가 조금 있는 것은 괜찮습니다. 앱도 똑같이 다시 시도해요.)
- **점검이 끝나면 구글 드라이브 `웹진` 폴더에서 `테스트01` ~ `테스트30` 폴더를 지워 주세요.** 그대로 두면 선생님 화면 학생 목록에 나타납니다.

## 수업 전 체크리스트

- [ ] `web-zine/js/config.js`의 `API_URL`이 `'mock'`이 아니라 내 웹 앱 주소로 바뀌었고, 푸시해서 GitHub Pages에 반영되었다.
- [ ] 관리자 비밀번호가 길게(12글자 이상) 설정되어 있다.
- [ ] 연습 학생 한 명을 만들어 보고 선생님 화면에 보이는지, 드라이브 `웹진` 폴더에 생겼는지 확인했다. 화면 위에 빨간 "연습 모드" 띠가 **보이지 않는다**.
- [ ] **30명 동시 사용 점검**(`load-check.mjs`)을 돌려 30/30 성공을 확인했고, 끝난 뒤 드라이브에서 `테스트01`~`테스트30` 폴더를 지웠다.
- [ ] 학생들에게 "카카오톡 안에서 열지 말고 Safari/Chrome에서 열기"를 안내할 준비가 되었다.
- [ ] **A3 PDF 한 장을 실제로 출력**해서 접어 보았다. 접었을 때 쪽 순서가 맞는지(1쪽이 표지로 앞에 오고 순서대로 넘어가는지) 확인했다.
- [ ] **아이폰 한 대로 테스트**했다: 갤러리에서 사진 올리기, **세로로 찍은 사진**도 똑바로 올라오는지 확인했다.
- [ ] 학생 이름은 중복되지 않게 정했다 (같은 이름은 같은 진으로 들어갑니다).
- [ ] 수업 후 `웹진` 폴더를 다운로드해 백업했다.
