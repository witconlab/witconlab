## 1. 기획 개요

### 1-1. 왜 만드는가
교부신청서의 세 번째 사업 축인 **‘성평등 콘텐츠 확산 플랫폼 구축’**을 온라인 창구로 구현한다.
2017년부터 쌓아 온 활동 기록, 자체 개발 교구, 그림책 교안을 한 곳에 모아 **보여주고(아카이브) → 써보게 하고(교구) → 직접 참여하게(책상자 체험단)** 만드는 것이 목표.

| 사업계획서의 목표 | 웹사이트에서의 역할 |
|---|---|
| 기존 콘텐츠 디지털화·고도화 (5종 이상) | **교구 소개** 메뉴에 디지털 교안·활용법 게시 |
| 체험형 가족캠프 (8/30, 11/29) | **활동 소개**에 캠프 기록·가족 실천 사례 아카이빙 |
| 콘텐츠 확산 플랫폼 (책상자 교육 10회, 온라인 체험단 125명) | **책상자 체험단 신청하기**로 모집·후기 수집 |
| 3개년 로드맵 (기반 구축 → 확산 → 모델화) | 사이트 자체가 2·3차년도 사례집·매뉴얼의 원천 데이터 |

### 1-2. 핵심 메시지
- 슬로건: **“가족의 일상에 스며드는 성평등 이야기”**
- 설립 정신: *“내가 만드는 우리 가족, 나와 네가 함께 만드는 우리 마을”*
- 관점: 성평등은 지식 전달이 아니라 **경험과 관계 속에서 형성되는 과정**

### 1-3. 주요 이용자
| 이용자 | 찾는 것 | 핵심 행동 |
|---|---|---|
| 치평동·광주 가족 (초등 자녀 부모) | 아이와 함께할 성평등 놀이, 캠프 소식 | 책상자 체험단 신청, 캠프 참여 |
| 기관·단체 (작은도서관, 학교 학부모회, 돌봄기관) | 교육 프로그램, 교구 활용 방법 | 방문 교육 신청, 교안 열람 |
| 지원기관·심사자 (광주여성가족재단, 서구청) | 활동 이력, 성과 | 연혁·활동 아카이브 열람 |
| 새나가온 회원·활동가 (13명) | 기록 업로드, 신청자 관리 | 시트로 콘텐츠 업데이트 |

## 3. 메뉴별 상세 기획

1. **히어로**: “가족의 일상에 스며드는 성평등 이야기” + 대표 캠프 사진 + CTA 2개 `책상자 체험단 신청` / `새나가온 알아보기`
2. **숫자로 보는 새나가온**: 2017 시작 · 여성친화마을 6년(2020~2025) · 가족캠프 ○회 · 자체 교구 6종 · 그림책 교안 24권 · 함께하는 기관 18곳
3. **사업 3축 카드**: 함께 만들자!(콘텐츠) / 함께 해보자!(가족 실천) / 함께 나누자!(마을 확산) → 각 메뉴로 연결

### 2. 교구 소개
**목록 화면**: 카드 그리드 + 필터(주제: 동의·거절 / 감정 / 고정관념 / 갈등 / 기후·환경, 대상: 유아·초등·가족·성인)

**자체 개발 교구 (6종)**
| 교구 | 연도 | 핵심 주제 | 비고 |
|---|---|---|---|
| STACK IT UP (카드게임) | 2024 | 성인지·성평등 아이스브레이킹 (경계, 거절, 동의, 소중한 몸 등) | 책상자 구성품 |
| STACK IT UP CUPS (컵타 버전) | 2024 | 몸으로 하는 협동 놀이 | |
| 손인형 퍼펫 | 2025 | 역할극으로 동의·거절 표현 연습 | |
| 감정 주사위 | 2025 | 감정 이름 붙이기, 감정 표현 | |
| 갈등상황 카드 | 2025 | 일상 갈등 상황에서 말하기 연습 | |
| 찾았다! 5R 보드게임 / 업사이클 그림책 놀잇감 | 2023 | 기후·자원순환 | 운천초·치평초·계수초 전달 |

**교구 상세 페이지 템플릿**
- 사진 갤러리 · 한 줄 소개
- 이렇게 놀아요: 대상 연령 / 인원 / 소요 시간 / 진행 순서 3~5단계
- 이야기 나누기 질문 (가족 대화 유도)
- 함께 읽으면 좋은 그림책 (교안 리스트와 연결)
- 디지털 자료: 활동지 PDF, 진행 영상·북트레일러 (2026 디지털화 결과물 5종 이상 게시 위치)
- “이 교구로 활동했어요” → 관련 활동 아카이브 링크

**성평등 그림책 교안 (24권)**
- 책 표지 그리드 → 클릭 시 책 정보 + 새나가온 교안 요약(주제, 질문, 연계 활동)
- 수록 예: 『탄생』, 『소중해 소중해 나도 너도』, 『내가 안아 줘도 될까?』, 『이럴 땐 싫다고 말해요!』, 『뜨개질하는 소년』, 『메리는 입고 싶은 옷을 입어요』, 『여자와 남자는 같아요』, 『내 탓이 아니야』, 『빨간 모자』 등
- 표지 이미지는 출판사 공개 이미지 범위에서 사용(저작권 확인 필요)

### 3. 활동 소개 (아카이브의 중심)
**① 2026 진행 중인 활동** — 진행 상태 배지
- 함께 모여요 (월 2회 정기회의) · 함께 다듬어요 (콘텐츠 점검·디지털화) · 함께 재구성해요 (책상자 기획)
- 1차 체험형 성평등 가족캠프 ‘함께 시작해요’ (8/30, 완료)
- 2차 성평등 실천 공유 캠프 ‘함께 나눠요’ (11/29, 예정)
- 책상자 활용 교육 ‘함께 배우기’ (기관 10회 목표) · 온라인 확산 ‘함께 이어가기’

**② 활동 아카이브** — 연도 탭(2020~2026) × 분류 칩 필터, 카드형 갤러리 → 상세 모달
| 분류 | 대표 기록 |
|---|---|
| 가족캠프 | 성인지 가족캠프(2022), 알쏭달쏭 가족경제교육 캠프·퍼플데이(2023), 호캉스 대신 파캉스 힐링캠프(2024), 크리스마스와 성인지 캠프·WITHMAS(2025) |
| 성평등 교육·지도사 양성 | 성평등 교육, 지도사 역량·실습과정(2023), 성인지 교육 |
| 그림책·북나들이 | 그림책으로 만나는 성평등(2020), 성인지 그림책 북나들이(2021), 작은도서관 북나들이(2024) |
| 인권놀이터 | 5·18 자유공원 탐방, 인권캠프(치평초 5학년), 권리를 품은 하루, 인권여권 스탬프투어(2024~25) |
| 교구 개발 | 그림책·보드게임 연구, 교구·교재개발 스터디, STACK IT UP 개발 |
| 마을 네트워크 | 치평 비비고, 모두의 치평살롱, 이락 MOU, 광마넷 한마당 |

상세 모달 필드: 제목 / 날짜 / 장소 / 분류 / 함께한 기관 / 사진 여러 장 / 짧은 기록글 / 사용한 교구·그림책 링크

**③ 가족 실천 이야기** — 캠프 이후 가족별 실천 기록(가족당 3~5건 목표)과 책상자 후기를 사례 카드로 노출. 3차년도 사례집의 원고가 된다.

### 4. 책상자 체험단 신청하기
**책상자란?** 집이나 기관에서 바로 펼쳐 볼 수 있는 성평등 실천 키트
- 구성(예산 산출내역 기준): 성평등 그림책 + STACK IT UP 카드게임 + 활동지 + 붙임딱지·스티커 + 디지털 자료 QR

**참여 방법 — 두 트랙**
| | 가정 체험단 (온라인) | 기관·단체 방문 교육 |
|---|---|---|
| 대상 | 광주 거주 가족 | 작은도서관, 학교 학부모회, 돌봄기관, 마을단체 |
| 규모 | 회차별 모집 (연 125명 목표) | 연 10회 이상 |
| 방식 | 책상자 수령 → 가정에서 활동 → 후기 공유 | 활동가가 찾아가 책상자로 교육 진행 |

**진행 절차 (4단계 인포그래픽)**: 신청 → 선정 안내(문자/메일) → 책상자 수령·활동 → 실천 기록 공유

**신청서 항목**
- 공통: 신청 유형(가정/기관), 신청자 이름, 연락처, 이메일, 거주 동/소재지
- 가정: 함께할 가족 구성(자녀 연령대), 신청 동기, 수령 방법(방문/택배)
- 기관: 기관명, 담당자, 예상 인원·대상 연령, 희망 일정
- 동의: 개인정보 수집·이용 동의(필수), 후기·사진 활용 동의(선택), 아동 초상권 동의(선택)

**후기 · FAQ**
- 체험 후기 카드(사진 + 한 줄 + 가장 좋았던 교구)
- FAQ: 비용은 있나요? / 몇 살부터 할 수 있나요? / 광주 외 지역도 되나요? / 책상자는 반납하나요?
- 스마트스토어 링크 (개설 후 연결 — 사업계획의 ‘스마트스토어 기반 확산’)

## 4. 디자인 방향
- **톤**: 그림책처럼 따뜻하고 친근하게. 딱딱한 ‘교육/캠페인’ 느낌을 피한다 (제안 배경의 문제의식과 일치).
- **컬러**: 신청서 도식에서 쓰인 보라·핑크 계열을 메인으로, 하늘색을 보조로 (사업 3축 = 하늘·보라·핑크).
  - 예: Primary `#7B4BB5`(보라), Accent `#E5458F`(핑크), Sub `#5AA9E6`(하늘), 배경 `#FFF9F3`(크림)
- **타이포**: 본문 Pretendard, 제목은 둥근 손글씨 계열(예: 카페24 써라운드, 나눔스퀘어라운드)
- **사진**: 활동 사진 중심의 큰 카드. 아동 얼굴은 동의 없으면 블러 처리.
- **모바일 우선**: 학부모 이용자 대부분이 모바일. 상단 탭 4개 상시 노출.

| 콘텐츠 관리 | 활동·교구·그림책 목록을 **구글 시트 CSV**로 관리하고 사이트가 불러옴 | 회원이 코드 없이 시트에 한 줄 추가하면 아카이브 갱신 |
| 사진 | 구글 드라이브 공유 폴더 또는 저장소 내 이미지(웹용 리사이즈) | |
| 신청서 | 구글 폼 임베드 또는 Apps Script로 시트 저장 | 신청자 명단이 바로 시트로 쌓여 선정·연락 관리 쉬움 |
| 성과 집계 | 신청 시트·후기 시트로 체험단 인원, 사례 건수 자동 집계 | 재단 결과보고(체험단 70~125명, 사례 30건)에 바로 활용 |

## 8. 확인이 필요한 사항
1. 책상자 정확한 구성품과 회차별 모집 인원·기간
2. 책상자 체험단 비용 여부(무료/택배비) 및 광주 외 지역 신청 허용 여부
3. 활동 사진의 아동 초상권 동의 범위 → 공개 가능한 사진 목록
4. 그림책 표지 이미지 사용 가능 여부(출판사 정책)
5. 도메인 사용 여부(예: saenagaon.kr) 또는 GitHub Pages 기본 주소 사용
6. 스마트스토어 개설 시기와 연결 방식
7. 공개할 대표 연락처(메일만 / 사무실 전화 포함)
