# 새나가온 아카이브 관리자 세팅 가이드

순서대로 한 번만 하면 됩니다. 처음 세팅에 30~40분 정도 걸립니다.
세팅이 끝나면 회원들은 **구글 시트만 고치면** 사이트가 바뀝니다. (회원용 안내는 별도 페이지)

---

## 전체 그림

구글 시트를 **두 개** 만듭니다. 섞으면 신청자 개인정보가 공개될 수 있어서입니다.

| 시트 | 내용 | 공개 여부 | 누가 편집 |
|---|---|---|---|
| ① **새나가온 아카이브 자료** | 활동·교구·그림책·가족 이야기 | 사이트가 읽도록 **웹에 게시** | 회원 전체 |
| ② **책상자 신청 명단** | 신청서 응답 | **절대 게시하지 않음** | 관리자·담당자만 |

사진은 구글 드라이브의 **공개용 사진 폴더**에 모읍니다.

---

## 1단계. 자료 시트 만들기

1. 구글 드라이브에서 [새로 만들기 > Google 스프레드시트]를 누르고, 이름을 `새나가온 아카이브 자료`로 바꿉니다.
2. 아래쪽 탭을 4개로 만들고 이름을 정확히 바꿉니다: `activities`, `tools`, `books`, `stories`
3. `activities` 탭을 누른 상태에서 [파일 > 가져오기 > 업로드]를 누르고 이 폴더의 `data/activities.csv`를 올립니다.
   - 가져오기 위치: **현재 시트 바꾸기**
   - 구분 문자 유형: **자동 감지**
   - ‘텍스트를 숫자, 날짜, 수식으로 변환’: **체크 해제** (2026.08.30 같은 날짜가 바뀌지 않게)
4. 나머지 탭도 같은 방법으로 `tools.csv`, `books.csv`, `stories.csv`를 가져옵니다.
5. 각 탭의 첫 줄(칸 이름)을 굵게 하고 [보기 > 고정 > 1행]으로 고정합니다.

## 2단계. 실수 막기 장치

6. **드롭다운 만들기** (`activities` 탭)
   - `category` 열(D열) 전체 선택 → [데이터 > 데이터 확인 > 규칙 추가 > 드롭다운]
     항목: 가족캠프, 성평등교육, 그림책·북나들이, 인권놀이터, 교구개발, 마을네트워크, 책상자, 공유회·수상
   - `status` 열(K열): 진행중, 예정, 완료
7. **첫 줄 보호하기**: 1행 선택 → [데이터 > 시트 및 범위 보호] → ‘수정 권한 설정’에서 **나만** 선택. 칸 이름이 바뀌면 사이트가 내용을 못 읽습니다.
8. **사용법 탭 추가**(선택): `사용법` 탭을 하나 더 만들어 회원용 안내 페이지 링크를 붙여 둡니다.

## 3단계. 웹에 게시하고 사이트에 연결하기

9. [파일 > 공유 > 웹에 게시]를 엽니다.
10. ‘링크’ 탭에서 왼쪽 상자는 `activities`, 오른쪽 상자는 **쉼표로 구분된 값(.csv)**을 고르고 [게시]를 누릅니다.
11. 나온 주소(`https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&single=true&output=csv`)를 복사합니다.
12. `js/config.js`를 열어 `activities: ''`의 따옴표 사이에 붙여 넣습니다.
13. 10~12번을 `tools`, `books`, `stories` 탭에도 반복합니다. (탭마다 주소가 다릅니다)
14. 같은 창 아래 ‘게시된 콘텐츠 및 설정’에서 **변경사항이 있을 때 자동으로 다시 게시**가 켜져 있는지 확인합니다.

> 시트를 고친 뒤 사이트에 반영되기까지 **보통 5분 안팎** 걸립니다. 바로 안 바뀌어도 정상입니다.

## 4단계. 사진 폴더 만들기

15. 구글 드라이브에 폴더 두 개를 만듭니다.
    - `새나가온 사진 원본` — 회원이 찍은 사진을 그대로 올리는 곳 (**링크 공유 끔**, 회원만 편집자로 초대)
    - `새나가온 공개용 사진` — 얼굴 블러가 끝난 사진만 두는 곳
16. `공개용 사진` 폴더 → [공유] → 일반 액세스를 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
    이 폴더에 넣은 사진은 공유 링크를 시트에 붙이면 사이트에 바로 나옵니다.
17. **얼굴 블러 담당자**를 정합니다. 담당자가 원본 폴더의 사진을 블러 처리해 공개용 폴더로 옮깁니다.
    - 휴대폰: 갤러리 앱의 편집 > 그리기/모자이크 기능, 또는 모자이크 앱
    - 많을 때: 원본 폴더 사진을 모아 Claude에게 “얼굴 블러 처리해서 photos 폴더에 넣어줘”라고 요청 (이번에 쓴 방법)

## 5단계. 책상자 신청서 연결

18. 드라이브에서 새 스프레드시트를 만들고 이름을 `책상자 신청 명단`으로 합니다. (**자료 시트와 다른 파일**)
19. [확장 프로그램 > Apps Script]를 엽니다.
20. 원래 있는 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 💾 저장합니다.
21. 오른쪽 위 [배포 > 새 배포] → 톱니바퀴에서 **웹 앱** 선택
    - 설명: `책상자 신청`
    - 다음 사용자 인증 정보로 실행: **나**
    - 액세스 권한이 있는 사용자: **모든 사용자**
22. [배포]를 누르면 권한 확인 창이 뜹니다. 내 계정 선택 → ‘Google에서 확인하지 않은 앱’이 나오면 [고급 > (안전하지 않음)으로 이동 > 허용]. 내가 만든 스크립트라 괜찮습니다.
23. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 `js/config.js`의 `APPLY_ENDPOINT`에 붙여 넣습니다.
24. 사이트에서 테스트 신청을 한 번 해 보고, 신청 명단 시트에 `책상자신청` 탭과 한 줄이 생겼는지 확인한 뒤 그 줄을 지웁니다.

> 나중에 `Code.gs`를 고치면 [배포 > 배포 관리 > ✏️ 수정 > 버전: 새 버전]으로 다시 배포해야 반영됩니다. (주소는 그대로)

25. 신청 명단은 담당자에게만 공유합니다. `진행 상태` 칸에 접수 → 선정 → 발송 → 후기완료 순으로 적어 관리합니다.
26. 모집을 닫을 때는 `js/config.js`의 `APPLY_OPEN: true`를 `false`로 바꿉니다.

## 6단계. 회원 초대

27. `새나가온 아카이브 자료` 시트 → [공유] → 회원 이메일을 **편집자**로 추가합니다.
28. 회원들에게 회원용 안내 페이지 링크를 보냅니다.
29. 실수로 지워져도 [파일 > 버전 기록 > 버전 기록 보기]에서 예전 상태로 되돌릴 수 있습니다.

## 7단계. 사이트 올리기 (GitHub Pages)

30. `js/config.js`를 고쳤으면 커밋하고 GitHub에 올립니다.
31. 저장소 [Settings > Pages]에서 배포 브랜치를 고르면 몇 분 뒤 주소가 나옵니다.
    - `config.js`는 시트 주소를 처음 넣을 때와 모집을 열고 닫을 때만 고치면 됩니다. 평소 자료 수정은 시트에서만 합니다.

내 컴퓨터에서 미리 볼 때는 `새나가온-아카이브` 폴더에서 아래 명령을 실행하고 http://localhost:8080 을 엽니다.

```bash
python3 -m http.server 8080
```

## 칸 쓰는 법 요약 (관리자용)

| 탭 | 칸 | 규칙 |
|---|---|---|
| activities | id | 겹치지 않는 영문 이름 (`2026-camp2`). 교구·가족 이야기와 연결할 때 씀 |
| | year | 연도 4자리, 기간이 없는 활동은 `상시` |
| | photos | 사진 여러 장은 `;` 또는 칸 안 줄바꿈(Alt+Enter)으로 구분. **첫 사진이 대표 사진** |
| | partners, tools | 여러 개는 `;` 또는 줄바꿈 |
| tools | howto, questions | 단계·질문마다 `\|` 또는 칸 안 줄바꿈 |
| | books | 그림책 id (`book03`) |
| books | theme | 같은 말끼리 묶여 필터가 됨 |
| stories | family | `치평동 ○○네`처럼 이름 대신 별칭. **후기 활용에 동의한 가족만** |

사진 칸에 쓸 수 있는 것:
- 구글 드라이브 공유 링크 (`https://drive.google.com/file/d/…/view?usp=sharing`) → 자동으로 이미지로 바뀝니다
- 사이트 폴더 안 사진 이름 (`p030` → `images/photos/p030.jpg`, `tools/puppet`)
- 그 밖의 이미지 주소 (`https://…jpg`)
