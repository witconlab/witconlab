# 새나가온 아카이브 리디자인 제안 (참고: outbox.kr)

> 지금 사이트의 구조와 구글 시트 데이터는 그대로 두고, **보이는 모습만** 바꾸는 제안입니다.

## 1. 아웃박스에서 가져올 점

| 아웃박스의 특징 | 왜 좋은가 | 새나가온에 적용 |
|---|---|---|
| 하얀 바탕, 넓은 여백, 가운데 1단 구성 | 사진과 글이 주인공이 됨 | 크림색 바탕 → 흰 바탕, 카드 그림자 제거, 여백 확대 |
| 두 줄짜리 거대한 슬로건 “교실을 예민하게 / 세상을 들썩이게” | 첫 화면에서 단체의 태도가 한 번에 전달됨 | 대구(對句) 슬로건을 아주 크게 |
| 표정 있는 도형 캐릭터 일러스트 | 성평등을 무겁지 않게, 친근하게 보이게 함 | **새나가온이 직접 만든 감정 주사위·토끼 퍼펫 얼굴**을 캐릭터로 |
| 정체성 한 문장 + ‘성평등’만 색 강조 | 무엇을 하는 곳인지 3초 안에 이해 | 같은 방식으로 한 문장 |
| ‘성평등 교육 업데이트’ 2열 카드 피드 | 계속 살아 있는 사이트처럼 보임 | 활동 시트 최신 글을 2열 피드로 (시트에 한 줄 쓰면 자동으로 맨 위에) |
| ‘아웃박스, 뭐가 다를까요?’ + 형광펜 라벨 소제목 + 넓은 사진 | 강점을 사진 한 장, 문장 두 줄로 설득 | ‘새나가온, 뭐가 다를까요?’ 3가지 |
| 진한 보라 단색 푸터 + SNS 아이콘 | 페이지 끝이 분명함 | 진보라 푸터 + 밴드 링크 |
| 오른쪽 아래 떠 있는 ‘문의’ 버튼 | 어디서든 바로 연락 | 떠 있는 ‘책상자 신청’ 버튼 |

**따라 하지 않을 점**
- 햄버거 메뉴(☰): 메뉴가 숨으면 회원·주민이 메뉴를 못 찾습니다. 지금처럼 **4개 탭을 항상 보이게** 둡니다.
- 스크롤해야 나타나는 빈 화면: 아웃박스는 내려야 내용이 뜨는 구간이 있습니다. 새나가온은 처음부터 다 보이게 만듭니다.

## 2. 콘셉트

**“그림책 한 권처럼 펼쳐지는 우리 마을 성평등 이야기”**

- 바탕: 흰색. 강조색은 지금의 보라를 유지하고, 사업 3축 색(하늘·보라·분홍)은 형광펜 라벨에만 씁니다.
- 글꼴: 제목은 굵고 동글한 한글 디스플레이 서체(예: Black Han Sans, Gasoek One 중 택1), 본문은 Pretendard 유지.
- 캐릭터: 감정 주사위의 여러 표정(웃음·놀람·화남·장난)과 토끼 퍼펫을 단순한 도형 캐릭터로 다시 그려 로고 옆·히어로·빈 화면에 씁니다. 다른 단체가 가질 수 없는 새나가온만의 얼굴이 됩니다.

### 슬로건 후보 (하나 골라 주세요)
1. **우리 집은 다정하게 / 우리 마을은 평등하게** ← 추천
2. 말할 땐 다정하게 / 놀 땐 평등하게
3. 그림책을 펼치면 / 마을이 달라져요

## 3. 홈 화면 구성 (위에서 아래로)

1. **헤더**: 로고 + 4개 탭 (지금과 같음, 더 얇게)
2. **히어로**: 거대한 두 줄 슬로건 → “광주 서구 치평동 마을공동체 새나가온” → 표정 캐릭터 무리 일러스트
3. **정체성 한 문장**: “새나가온은 그림책과 놀이로 가족의 일상에 **성평등**을 심는 마을공동체입니다.”
4. **새나가온 소식**: 활동 시트의 최신 6건을 2열 카드(사진 + 제목)로. ‘더 보기’ 버튼
5. **새나가온, 뭐가 다를까요?** — 형광펜 라벨 + 넓은 사진 + 두 줄 설명
   - [하늘] **마을에서 시작해요** — 작은도서관·학교·주민자치회 17곳과 함께 (사진: 치평 비비고)
   - [보라] **직접 만든 교구로 놀아요** — STACK IT UP, 감정 주사위… 회원이 공부하고 만든 교구 (사진: 교구 전시)
   - [분홍] **가족이 함께 실천해요** — 2022년부터 이어 온 가족캠프 (사진: 퍼플데이)
6. **책상자 체험단 띠 배너**
7. **진보라 푸터** + 밴드 아이콘 + 오른쪽 아래 떠 있는 ‘책상자 신청’ 버튼

지금 홈에 있는 숫자 6칸(2017, 6년, 41…)은 빼고, 숫자는 ‘새나가온이란?’ 연혁 쪽으로 옮깁니다.

## 4. 하위 페이지

| 페이지 | 바뀌는 점 |
|---|---|
| 새나가온이란? | 머리 제목을 히어로처럼 크게. 연혁은 큰 연도 숫자 + 짧은 줄, 로드맵은 형광펜 라벨 3단 |
| 교구 소개 | 교구 카드를 정사각형 사진 중심으로, 상세는 블로그 글처럼 세로로 긴 ‘교구 이야기’ 형식 |
| 활동 소개 | 2열 큰 사진 피드로 바꾸고 글자는 날짜·제목만. 연도·분야 필터는 위쪽 한 줄로 단순하게 |
| 책상자 신청 | 신청서 위에 캐릭터가 책상자를 든 일러스트, 단계 안내는 형광펜 라벨로 |

## 5. 진행 방법

- 구글 시트 칸과 데이터는 **바꾸지 않습니다.** 회원들이 쓰는 방법도 그대로입니다.
- 새 브랜치에서 홈 → 하위 페이지 순으로 바꾸고, 지금 버전과 나란히 비교해 보신 뒤 고르시면 됩니다.
- 정해 주실 것: ① 슬로건 ② 제목 서체(시안 2개로 비교 가능) ③ 밴드·인스타그램·카카오 채널 주소(있다면)
