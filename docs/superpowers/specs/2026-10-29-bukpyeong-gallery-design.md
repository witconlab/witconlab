# 북평데이 수강생 작품 갤러리 설계

## 목적
북평데이 책자에 실린 QR로 꽃대어른학교 AI과정 수강생 작품을 휴대폰에서 웹 갤러리처럼 보게 한다. 행사장 모니터에서는 영상 모음을 반복 재생하고, A3 포스터로 갤러리를 안내한다.

## 원본
`~/Downloads/꽃대어른학교_AI 과정 /2026_꽃대어른` (차시별 폴더, 약 570개 파일)
- 제외: 수업 중 캡처 사진, 복습 교재, 커리큘럼, 같은 파일 중복본

## 결과물
1. **QR1 카드뉴스·정보 자료 갤러리** — `bukpyeong-gallery/cardnews/`
   - 차시별 묶음, 바둑판 썸네일, 누르면 크게 보고 넘기기. PDF는 휴대폰에서 바로 열기.
   - 네이버 QR `m.site.naver.com/2jgeU` (현재 챕터1 드라이브) → 이 주소로 변경(사용자가 직접)
2. **QR2 영상 갤러리** — `bukpyeong-gallery/videos/`
   - 영상은 휴대폰용 720p로 압축해 저장소에 올림.
   - 네이버 QR `m.site.naver.com/2jgfo` (현재 챕터4 드라이브) → 이 주소로 변경(사용자가 직접)
3. **현장 모니터 영상** — 가로 1920×1080 한 편, 반복 재생용 로컬 파일(저장소에 올리지 않음)
   - 잘 된 영상: 한 편씩 가운데, 양옆은 같은 영상 흐림 배경, 원본 소리 재생
   - 나머지: 세로 영상 2~3개 나란히, 소리 없음(또는 잔잔한 배경음)
   - 곰 캐릭터 영상은 잘 된 것만, 말바우시장 소개는 등장 인물별로 잘 된 것만
   - CapCut·NotebookLM 엔딩 로고 잘라내기, 모서리 CapCut 표시는 흐림 처리
4. **A3 안내 포스터** — `bukpyeong-gallery/poster.html` + `poster-A3.pdf`
   - 기존 `북평데이-AI체험부스-포스터`와 같은 글꼴(Ddeoksang)·색감, QR1·QR2(네이버 QR) 수록

## 공개 범위
- 메인 index.html에 링크하지 않음. 페이지에 `noindex` 설정.
- 공개 저장소이므로 주소를 아는 누구나 볼 수 있음.

## 작업자 판단(사용자 확인 전)
- 작품마다 만든 사람 이름은 표시하지 않음
- 작품 선별은 작업자가 먼저 고르고 목록으로 확인받음
- PPT 중 PDF와 겹치지 않는 정보 자료는 Keynote로 PDF 변환해 포함
