# 실습용 웹 진(Zine) 제작 사이트 — 설계

작성일: 2026-11-05 · 상태: 검토 중

## 1. 무엇을, 왜

교육생이 현장에서 사진으로 모은 이야기를 **8쪽짜리 미니 진**으로 엮는 실습 도구다.
흐름은 기획 → 현장 사진 수집 → 사이트 접속 → 1쪽부터 한 쪽씩 채우기 → 완성 후 e-book으로 보기·PDF 내려받기 → 선생님이 A3로 출력해 자르고 접어 실물 책 완성.

영감: 통영 「저마다의 통영」 수업 결과물 — 종이 질감 위 사진 콜라주, 노란 알파벳 동그라미 스티커, 번호 동그라미, 색연필 별·손그림, 손글씨 설명. 화면 위 결과물이 이 손맛을 닮아야 한다.

성공 기준
- 교육생이 휴대폰만으로 수업 시간 안에 8쪽을 채운다.
- 선생님이 A3로 뽑아 접었을 때 쪽 순서와 방향이 정확히 맞는 책이 된다.
- 교육생 사진과 작업은 선생님 구글 드라이브에 남고, 나중에 다시 들어와 고칠 수 있다.

## 2. 목표 / 비목표 / 반드시 피할 것

**목표**
- 반응형 편집기(휴대폰 우선, 태블릿·PC 지원)
- 쪽마다 사진·스티커·자막·제목·배경 편집
- e-book 보기(휴대폰 한 쪽씩, 넓은 화면은 펼친 두 쪽)
- 쪽 순서 PDF(누구나), A3 접기용 PDF(관리자만)
- 구글 드라이브에 교육생별 자료 보관
- 완성 후에도 수정 가능

**비목표(이번에 안 함)**
- 구글 로그인·회원가입, 여러 명 동시 편집, 동영상, 인쇄소용 CMYK·재단 여백(bleed), 오프라인 편집, 8쪽 외 쪽수

**반드시 피할 것(동작해도 실패)**
- 교육생 작업이 사라짐(저장 실패를 모른 채 넘어감)
- 화면과 PDF가 다르게 나옴(글꼴 깨짐, 사진 빠짐, 위치 어긋남)
- A3를 접었을 때 쪽 순서·방향이 틀림
- 다른 교육생이 내 진을 고칠 수 있음
- 교육생 사진이 인터넷에 공개 링크로 풀림

## 3. 정해진 것(사용자 결정)

- **판형**: A3 한 장 → 8쪽, 한 쪽 = A6(105×148mm) 세로.
- **쪽 구성**: 1쪽 표지, 2–7쪽 내용, 8쪽 뒷표지. 쪽마다 제목.
- **A3 배열**(시안에서 승인): A3 가로 4칸×2줄.
  - 윗줄(180° 뒤집어 인쇄): 5 · 4 · 3 · 2
  - 아랫줄(정방향): 6 · 7 · 8(뒷표지) · 1(표지)
  - 가로로 반 접고 가운데 두 칸 경계선(가로 중앙선의 가운데 절반)만 칼집 → 밀어 접기.
- **저장소**: 선생님의 구글 드라이브 — **개인 Gmail 계정**(Workspace 정책 제한 없음, Apps Script 웹 앱을 "나로 실행 / 모든 사용자" 접근으로 배포 가능).
- **권한**: A3 접기용 출력은 관리자(선생님)만.
- **디자인 톤**: 시안 [2026-11-05-web-zine-mockup.html](2026-11-05-web-zine-mockup.html)(크림색 종이 #f6efdc, 노란 알파벳 스티커, 번호 동그라미, 빨강·초록 색연필 별, 손글씨 자막).
- **화면(UI) 참고**(사용자 제공 다이어리 앱 캡처 4장, 2026-11-05): 분위기만 참고하고 그 앱의 캐릭터·그림은 복제하지 않는다. 스티커는 모두 자체 제작.
  - 미색 종이 + 연한 점/모눈 무늬, 쪽 안쪽에 얇은 진한 테두리 선.
  - 쪽 왼쪽 위에 큰 쪽 번호 + 밑줄(예: `3` ‾‾ ), 제목은 가운데 손글씨 + 뒤에 반투명 형광펜 띠.
  - 본문 자막은 가운데 정렬 손글씨.
  - 사진은 폴라로이드 틀(흰 테두리, 아래가 두꺼움) 선택 가능.
  - 스티커는 손그림 느낌의 둥근 얼굴 덩어리(여러 색·표정), 해·음표·반짝이·잎 같은 낙서, 알파벳 글자.
  - 하단 도구는 단순한 선 아이콘. 스티커 시트는 위에 탭(최근·얼굴·낙서·별·숫자·알파벳·선생님), 아래 큰 격자.

## 4. 화면과 동작

### 4.1 입장
- 반은 하나뿐이라 반 구분은 없다. 교육생: **이름 + 숫자 4자리 비밀번호**로 입장. 처음 입장하면 그 조합으로 내 진이 만들어진다. 이미 있는 이름이면 비밀번호가 맞아야 들어가고, 처음 만드는 사람이 같은 이름을 쓰려 하면 이름 뒤에 구분(예: 김민지2)을 붙이게 안내.
- 관리자: 별도 주소(`/admin`)에서 관리자 비밀번호로 입장.
- 입장 정보는 그 기기에 기억(다음엔 바로 내 진으로).

### 4.2 편집기
- 상단: 진 제목·저장 상태 배지(저장 중 / 저장됨 / **저장 실패 – 다시 시도**).
- 1~8쪽 미리보기 줄. 표지·뒷표지는 색으로 구분.
- 가운데: A6 비율 쪽 캔버스. 인쇄 안전선(가장자리 5mm) 점선 표시 — 이 밖의 요소는 잘릴 수 있음을 알림.
- 하단 도구: **사진 / 스티커 / 자막 / 제목 / 배경**.
  - 사진: 휴대폰 앨범·카메라에서 선택(여러 장). 올리기 전 기기에서 긴 변 1800px, JPEG로 줄인다(A6 300dpi ≈ 1240×1748px).
  - 스티커: 기본 묶음 — 둥근 얼굴 덩어리 9색(웃음·무표정·찡그림 등), 낙서(해·음표·반짝이·잎·하트·구름), 노란 알파벳 동그라미 A–Z, 컬러 알파벳 글자 A–Z(빨강·노랑·파랑), 번호 동그라미 01–15, 색연필 별(빨강·초록), 마스킹테이프 3색. 최근 쓴 스티커 12개를 '최근' 탭에 보여준다. 관리자가 PNG 스티커 묶음을 추가할 수 있다.
  - 자막: 손글씨 글꼴 텍스트 상자, 글자 크기·색(검정·빨강·파랑·흰색) 선택.
  - 제목: 쪽마다 한 줄(쪽 위쪽 기본 위치, 이동 가능).
  - 배경: 크림·노랑·하늘·연두·흰색 종이색 × 무늬(점·모눈·없음), 테두리 선 켜기/끄기.
  - 사진 틀: 없음 / 폴라로이드.
- 요소 조작: 끌어 이동, 모서리 핸들(PC) 또는 두 손가락(휴대폰)으로 크기·회전, 앞으로/뒤로, 복제, 삭제.
- 요소 위치·크기는 쪽 크기 대비 비율로 저장(화면 크기와 무관하게 같은 결과).
- 변경 후 약 1.5초 뒤 자동 저장. 실패하면 배지로 분명히 알리고 기기에 임시 보관 후 재시도.
- 되돌리기/다시하기.

### 4.3 e-book 보기
- 휴대폰: 한 쪽씩, 좌우 쓸어넘기기. 넓은 화면: 1쪽 단독 → 2-3 → 4-5 → 6-7 → 8 단독, 화살표·키보드로 넘김.
- 교육생이 "완성" 표시를 해도 계속 수정 가능.
- 버튼: **PDF 내려받기(쪽 순서)**.

### 4.4 관리자
- 교육생 목록과 진행도(채워진 쪽 수, 마지막 수정 시각, 완성 여부).
- 교육생 진 열람(e-book), 비밀번호 초기화.
- **A3 접기용 PDF**: 한 명 또는 여러 명 선택 → 한 사람당 A3 가로 한 장인 PDF. 접는 선·칼집 선을 아주 연한 선으로 표시(끄기 가능).
- 스티커 묶음 추가.

## 5. 데이터와 저장

- 선생님 드라이브 구조:
  ```
  웹진/
    이름/
      zine.json      (쪽·요소 데이터)
      photos/        (올린 사진)
    stickers/          (관리자 추가 스티커)
  ```
- zine.json 개요: 이름·비밀번호 해시·제목·완성 여부·수정 시각, `pages[8]` — 각 쪽 `{title, titleBox, background, pattern, frameLine, elements[]}`, 요소 `{type: photo|sticker|text, src|text, x, y, w, h(쪽 대비 0–1), rotate, z, style}`.
- 사진 파일은 **공개 링크로 공유하지 않는다**. 사이트는 중간 서버를 통해서만 사진을 받는다.

## 6. 구성(기술) — 내가 정한 것

- **화면**: 기존 저장소(`witconlab/witconlab`, GitHub Pages)의 새 폴더 `web-zine/`. 빌드 없는 HTML/CSS/JS(기존 사이트와 같은 방식). 필요한 라이브러리는 CDN 고정 버전.
- **중간 서버**: 선생님 구글 계정에서 실행되는 **Google Apps Script 웹 앱**. 입장 확인, zine.json 읽기·쓰기, 사진 올리기·내려받기, 관리자 기능을 맡는다. 드라이브 접근 권한은 이 스크립트만 가진다. 관리자 비밀번호는 스크립트 속성에 저장.
- **PDF**: 브라우저에서 zine.json을 직접 캔버스에 그려 만든다(화면 캡처 방식 아님). 쪽 PDF는 A6 8쪽, A3 PDF는 A3 가로에 8칸 배치·윗줄 180° 회전. 해상도 300dpi 기준. 손글씨 글꼴은 그리기 전에 반드시 로드 완료를 확인.
- **글꼴**: 본문 Pretendard, 손글씨 자막 Nanum Pen Script(또는 Gaegu) — 둘 다 무료 웹폰트.

### 6.1 내가 정한 운영 기준 (검토 후 추가)

- **동시 사용 규모**: 교육생 최대 50명이 동시에 편집하는 상황을 기준으로 설계. Apps Script 동시 실행 한도(약 30)를 넘지 않도록 자동 저장은 마지막 변경 후 3초 뒤 한 번으로 묶고, 사진은 한 장씩 차례로 올리며 실패 시 자동 재시도. 저장·사진 올리기는 서버에서 반 전체를 줄 세우는 잠금을 쓰지 않고, 버전 번호(rev) 비교와 저장 ID(saveId)로 오래된 저장이 새 저장을 덮지 않게 한다(잠금은 새 학생 만들기와 관리자 작업에만). 선생님이 바꾼 비밀번호는 진 파일이 아니라 스크립트 속성에 저장해 학생 저장과 겹치지 않게 한다. 50명 동시 접속 부하 테스트 1회.
- **비밀번호 보호**: 숫자 4자리 유지. 5번 틀리면 그 진은 10분 동안 입장 잠금 후 자동 해제(수업이 멈추지 않도록). 관리자는 즉시 해제·비밀번호 초기화 가능.
- **설치**: 선생님이 직접 할 수 있게 단계별 설치 안내서(화면 캡처 포함)와 복사해 붙일 스크립트 한 파일, 드라이브 폴더를 자동으로 만드는 `설치하기` 함수를 제공. 업데이트 때는 같은 배포를 수정해 주소가 바뀌지 않게 하는 방법을 안내서에 포함.

## 7. 확인 방법

- A3 PDF를 실제로 출력해 접어 보고 1→8쪽 순서·방향이 맞는지 확인(필수, 최초 1회).
- 휴대폰(iOS Safari, 안드로이드 Chrome)에서 사진 올리기·두 손가락 조작·자동 저장 확인.
- 같은 진의 화면·e-book·쪽 PDF·A3 PDF가 같은 모습인지 비교.
- 네트워크를 끊은 상태에서 편집 → 저장 실패 표시 → 다시 연결 후 저장되는지 확인.

## 8. 빌더에게 맡기는 것

- 화면 세부 디자인(시안 톤 유지), 터치 조작 구현 방식, 사진 캐시 방식, 스티커 그림 제작, 쪽 넘김 애니메이션.
