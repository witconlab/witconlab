# 시민기록교육 3~5차시 — 물음표·느낌표로 만드는 우리 동네 진 (수업 설계)

작성일: 2026-11-06 · 상태: 담당자 사전 미팅용 초안

## 1. 개요
- 대상: 50~80대 지역 주민 50명, 테이블 5개 × 10명. 3·4차시는 테이블마다 퍼실리테이터 1명.
- 시간: 차시별 2시간 (14:00~16:00). 전체 과정 5회 중 3·4·5차시를 맡는다.
- 장소: 3차시 복합커뮤니티 송정다누리 · 4·5차시 신흥동행정복지센터 2층 (4차시 산책은 신흥동 행정복지센터 주변).
- 선행: 교육생은 이 강의 전에 「쉽게 시작하는 시민기록교육」에서 15가지 기록 방법을 배우고 온다.
- 연결 고리: 『매일의 영감 수집』의 **경험 → 수집 → 물음표(?) → 느낌표(!)**.
  - 물음표 = 호기심과 질문 ("스쳐 지나가던 익숙한 풍경에 질문 던지기")
  - 느낌표 = 발견과 이야기 ("나만의 시선으로 조각을 이어 매거진 만들기")
- 결과물: 1인 1권 8쪽 미니 진(웹 제작 → A3 출력 → 접어서 책), 내년 기록화 사업 공모 원페이퍼.
- 인쇄: 모든 활동지는 **A3 흑백**. 글자 크게(본문 14pt 이상), 쉬운 말, 고르는 칸 먼저, 예시 함께.

## 2. 15가지 기록 방법 → 다섯 묶음 (쉬운 말)
| 묶음 | 방법 (원래 번호) | 산책 중 바로? |
|---|---|---|
| 눈으로 찍기 | 오래된 간판(01), 골목 색깔(02), 바닥 무늬(05), 틈새 풀꽃(06), 집 앞 화분(08) | 예 |
| 손으로 그리기 | 지금 모습 그리기(03), 걸은 길 그리기(15) | 예 · 그린 것은 사진으로 찍어 웹 진에 (문질러 본뜨기(04)는 인원이 많아 제외) |
| 귀로 듣기 | 동네 소리 글로 적기(12), 동네 말 모으기(14), 이웃 이야기(13) | 예 |
| 몸으로 느끼기 | 걸은 길 그리기(15), 볕·바람·그늘(11), 고양이·새 따라가기(07) | 예 |
| 찾아서 담기 | 옛 신문·기사(09, 검색→캡처), 옛 하늘(항공)사진(10, 사이트 캡처), 예전 모습 사진(03 비포) | 교육장에서 휴대폰으로 |

## 3. 차시별 흐름
### 3차시 — 기획: 내 주변에서 물음표와 느낌표 찾기 (2시간)
| 시간 | 활동 | 활동지 |
|---|---|---|
| 15분 | 여는 이야기: 『매일의 영감 수집』 "사소한 것들을 발견하는 힘", 지난 수업 15가지 돌아보기 | |
| 20분 | 경험: 휴대폰 사진첩에서 지난 한 달 사진 3장 → 짝에게 "왜 찍었는지" | ① 나의 조각 3개 |
| 25분 | 수집: 다섯 묶음 중 해 보고 싶은 것 ○, 가장 하고 싶은 것 ★. 같은 ★끼리 4차시 산책 짝 | ② 모아 보고 싶은 방법 |
| 10분 | 쉬는 시간 | |
| 25분 | 물음표 → 느낌표: 조각마다 "왜 눈에 띄었을까?" → "아하, ~구나". 테이블에서 돌아가며 | ③ 물음표·느낌표 |
| 20분 | 내 진 기획: 제목 가안, 8쪽 그림판, 한 줄 소개, 산책 미션 카드 | 뒷면 ④⑤⑥ |
| 5분 | 닫기: 4차시 준비물(휴대폰 충전, 편한 신발, 미션 카드) | |

### 4차시 — 수집과 제작: 동네 산책 → 웹으로 진 만들기 (2시간)
| 시간 | 활동 |
|---|---|
| 10분 | 미션 카드 다시 읽기, 테이블별 산책 경로·약속 시간 안내 |
| 40분 | 동네 산책 (테이블 단위, 퍼실 동행): 미션 카드 따라 사진·소리 적기·그리기·이웃 이야기 |
| 10분 | 돌아와 쉬기, 사진 고르기 (8장 이내) |
| 50분 | 웹 진 만들기: 입장(이름+숫자 4자리) → 표지부터 8쪽 → 사진 넣고 자르기, 스티커, 자막 (큰 글씨 모드 권장). 찾아서 담기(캡처)는 이때 |
| 10분 | e-book 미리보기로 서로 넘겨 보기, "다 만들었어요" |
- 진행자는 수업 후 관리자 화면에서 A3 접기용 PDF를 10명씩 묶어 출력해 5차시에 가져간다.

### 5차시 — 출판과 공유, 그리고 내년: 내 책 만들기 → 공유회 → 원페이퍼 (2시간)
| 시간 | 활동 |
|---|---|
| 25분 | A3 출력물 자르고 접어 책 만들기 (접는 법 시연) |
| 35분 | 공유회: 테이블 안에서 1인 2분 "내 책 한 줄 소개"(3차시 ⑤) → 테이블 대표 1권 전체 소개 |
| 10분 | 쉬는 시간 |
| 40분 | 내년 기록화 사업 원페이퍼: 질문지에 답하기(개인 또는 테이블 팀) → 원페이퍼 완성 |
| 10분 | 테이블별 원페이퍼 한 장씩 발표, 닫기 |

## 4. 원페이퍼 (일반 공모 양식 — 정해진 양식 없음, 진행자 판단)
질문(쉬운 말) → 계획서 칸:
1. 어느 동네의 무엇을 기록하고 싶나요? → 사업명 / 기록 대상·장소
2. 왜 지금 기록해야 하나요? (내 물음표) → 추진 배경
3. 기록해서 무엇을 남기고 싶나요? (내 느낌표) → 목적
4. 누구와 함께하나요? → 참여 대상·인원
5. 어떤 방법으로 모으나요? (다섯 묶음 체크) → 기록 방법
6. 언제, 몇 번 하나요? → 추진 일정
7. 무엇이 만들어지나요? (진·전시·지도…) → 결과물
8. 동네에 무엇이 좋아지나요? → 기대효과
9. 무엇이 필요한가요? (항목 체크 + 대략 금액) → 예산
한 줄 요약(사업 소개 한 문장) → 맨 위 요약
