# 웹 진(Web Zine) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 교육생이 휴대폰으로 8쪽 미니 진을 편집하고, e-book으로 보고 PDF로 받으며, 관리자가 A3 접기용 PDF를 뽑는 사이트.

**Architecture:** GitHub Pages에 올리는 빌드 없는 정적 사이트(`web-zine/`, ES 모듈) + 선생님 개인 Gmail에서 실행되는 Google Apps Script 웹 앱(드라이브 저장 담당). 진은 JSON 한 개(`zine.json`)로 표현되고, 화면·썸네일·PDF가 모두 같은 캔버스 렌더러(`render.js`)로 그려진다.

**Tech Stack:** HTML/CSS/ES modules, jsPDF 2.5.1 (cdnjs), Pretendard 1.3.9 (jsDelivr), Nanum Pen Script (Google Fonts), Google Apps Script (V8), 테스트는 Node 24 내장 `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-05-web-zine-design.md` (시안: `docs/superpowers/specs/2026-11-05-web-zine-mockup.html`)

## Global Constraints

- 8쪽 고정: 1 표지, 2–7 내용, 8 뒷표지. 쪽 크기 A6 105×148mm 세로.
- A3 배열(가로 420×297mm, 4칸×2줄): 윗줄 왼→오 5·4·3·2(180° 회전), 아랫줄 6·7·8·1(정방향). 칼집 = 가로 중앙선 중 x 105–315mm.
- 인쇄 안전선: 쪽 가장자리 5mm.
- 요소 좌표 `x, y, w, h`는 쪽 크기 대비 0–1 비율, `rotate`는 도(deg).
- 사진: 올리기 전 긴 변 최대 1800px, JPEG 품질 0.85.
- 자동 저장: 마지막 변경 후 3000ms에 한 번. 사진은 한 장씩 순서대로, 실패 시 재시도.
- 입장: 이름 + 숫자 4자리 비밀번호(반 구분 없음). 5번 틀리면 10분 잠금 후 자동 해제.
- 드라이브 구조: `웹진/이름/zine.json`, `웹진/이름/photos/`, `웹진/stickers/`. 사진은 공개 공유하지 않음.
- 종이색: 크림 `#f6efdc`, 노랑 `#ffe9a8`, 하늘 `#dbeefa`, 연두 `#e4f1d0`, 흰색 `#ffffff`. 자막 색: 검정 `#2b2620`, 빨강 `#e8473a`, 파랑 `#2f6fb3`, 흰색 `#ffffff`.
- 글꼴: 본문 Pretendard, 손글씨 `Nanum Pen Script`.
- 화면 톤: 스펙 3절 "화면(UI) 참고" — 점/모눈 종이, 얇은 테두리 선(`#3a3530`, 쪽 안쪽 5mm), 왼쪽 위 쪽 번호+밑줄, 형광펜 띠 제목, 가운데 정렬 손글씨, 폴라로이드 사진 틀, 선 아이콘 도구. 참고 앱의 캐릭터·그림은 복제 금지, 스티커는 자체 SVG.
- PDF 300dpi 기준(A6 = 1240×1748px).
- 모든 화면 문구는 한국어.
- 외부 스크립트는 정확한 버전 고정 CDN만.

## Review Focus

1. **아이폰 원본 사진(HEIC·4000px 이상·세로 회전 정보)** → 브라우저가 디코드한 방향 그대로, 긴 변 1800px JPEG로 올라가야 한다. → Task 6 `fitWithin` 테스트 + Task 11 수동 확인.
2. **저장 도중 네트워크 끊김/탭 닫힘** → 작업이 기기에 백업되고, 다시 열면 서버본보다 새 백업을 복원해 재저장. → Task 5 `saver` 테스트(`backup restored when newer`).
3. **긴 한국어 자막** → 띄어쓰기 없어도 글자 단위로 줄바꿈되어 상자 안에 그려지고, 화면과 PDF 줄바꿈이 같다. → Task 3 `wrapText` 테스트.
4. **손글씨 글꼴이 아직 안 받아진 상태에서 PDF 만들기** → 글꼴 로드를 기다린 뒤 그린다. → Task 8 `ensureFonts` 호출 순서 테스트.
5. **두 기기(또는 두 탭)에서 같은 진 편집** → 오래된 쪽이 최신 저장을 덮어쓰지 않고 "다른 곳에서 수정됨, 새로고침" 안내. → Task 1 `rev` 충돌 테스트 + Task 5 처리.

### Task 1: Apps Script 백엔드

**Files:**
- Create: `web-zine/apps-script/Code.gs`, `web-zine/tests/gas-harness.mjs`, `web-zine/tests/backend.test.mjs`

**Interfaces:**
- Produces (HTTP): `doPost(e)` — 본문은 JSON 문자열(`Content-Type: text/plain`, CORS 프리플라이트 회피), `{action, ...}`. 응답 `{ok:true, ...}` 또는 `{ok:false, error:"<코드>", message:"<한국어>"}`.
  - `login {name, pin}` → `{token, zine, created:boolean}` / 오류 `BAD_PIN {remaining}`, `LOCKED {until}`, `BAD_INPUT`
  - `load {token}` → `{zine}`
  - `save {token, zine}` → `{rev}` / `CONFLICT {rev}` (요청 `zine.rev` ≠ 저장된 rev)
  - `uploadPhoto {token, data(base64), mime}` → `{photoId}`
  - `getPhoto {token|adminToken, photoId}` → `{data, mime}`
  - `listStickers {}` → `{stickers:[{id,name}]}`; `getSticker {id}` → `{data,mime}`
  - `adminLogin {password}` → `{adminToken}`
  - `adminList {adminToken}` → `{students:[{name, filledPages, updatedAt, done, lockedUntil}]}`
  - `adminGetZine {adminToken, name}` → `{zine}`
  - `adminResetPin {adminToken, name, pin}`, `adminUnlock {adminToken, name}`, `adminAddSticker {adminToken, name, data, mime}` → `{ok:true}`
  - 토큰 오류는 `AUTH`.
- Produces (설치): `setup()` — `웹진`, `웹진/stickers` 폴더 생성, `ROOT_FOLDER_ID` 저장. 관리자 비밀번호는 스크립트 속성 `ADMIN_PASSWORD`(SETUP.md에서 수동 입력).
- 저장: 토큰은 `CacheService` 6시간(`tok_<uuid>` → 이름, `adm_<uuid>` → "admin"). 실패 횟수·잠금은 스크립트 속성 `fail_<이름>` = `{count, until}`. 비밀번호는 `SHA-256(salt + pin)` 16진수, salt는 학생별 무작위, zine.json의 `auth` 필드에 저장하되 `load`/`adminGetZine` 응답에서는 제거. 쓰기는 `LockService.getScriptLock().waitLock(20000)`.
- `zine.rev`: 저장할 때마다 서버가 +1.

- [ ] **Step 1: 하네스 작성** — `gas-harness.mjs`: `loadGas(path)`가 `vm.createContext`에 메모리 기반 `DriveApp`(폴더·파일 트리, `createFolder/getFoldersByName/getFilesByName/createFile/getFileById/getBlob().getBytes()/setContent`), `PropertiesService.getScriptProperties()`, `CacheService.getScriptCache()`, `LockService`, `Utilities`(`computeDigest`, `base64Encode/Decode`, `getUuid`, `newBlob`), `ContentService`를 넣고 Code.gs를 실행해 `{ctx, call(action, body)}`를 돌려준다. `call`은 `doPost({postData:{contents:JSON.stringify(...)}})`의 결과 텍스트를 JSON으로 파싱. 시간은 `ctx.__now` 로 조절 가능하게 `Date.now`를 감싼다.

### Task 3: 캔버스 렌더러 + 스티커

**Files:** Create `web-zine/js/render.js`, `web-zine/js/stickers.js`, `web-zine/tests/render.test.mjs`

**Interfaces:**
- Consumes: Task 2 `PAPERS`, `TEXT_COLORS`, Element.
- Produces:
  - `stickers.js`: `BUILTIN_STICKERS: Array<{key, group:'face'|'doodle'|'star'|'number'|'alpha'|'letter'|'tape', label, svg:string, aspect:number}>` — 그룹: 얼굴 덩어리 9색(`#e8474f`,`#3fbf6b`,`#f5a3a3`,`#c9a7d8`,`#f58a2e`,`#f7d348`,`#c4c8c8`,`#3d5a8c`,`#8fb3d9`)×표정(웃음·무표정·찡그림 중 색마다 하나, 울퉁불퉁한 원 path + 검정 점 눈·선 입), 낙서(해·음표·반짝이·잎·하트·구름, 검정 외곽선 손그림 느낌), 컬러 알파벳 글자 A–Z 3색(`#e8473a`,`#f7c948`,`#2f6fb3`, Pretendard 900 + 흰 외곽선), 노란 알파벳 동그라미 A–Z(`#ffe14d` 원 + 검정 굵은 글자), 번호 동그라미 01–15(`#e9b93a` 원 + 흰 글자), 색연필 별 빨강 `#e8473a`·초록 `#3fae49`(거친 손그림 느낌 path), 마스킹테이프 3색(반투명 사각형, 톱니 끝), 하트, 음표. `stickerSvg(key) → string`. **글자가 들어간 스티커(알파벳 동그라미·컬러 글자·번호 동그라미)는 SVG가 아니라 `draw(ctx, w, h)` 함수로 정의**한다 — 이미지로 그린 SVG는 웹폰트를 쓰지 못해 기기마다 글자가 달라지기 때문. 항목은 `svg` 또는 `draw` 중 하나를 가진다. 편집기 DOM 표시는 같은 `draw`로 그린 작은 캔버스를 쓴다.
  - `render.js`:
    - `wrapText(measure:(s)=>number, text, maxWidth) → string[]` — 공백 기준으로 줄을 나누되 한 단어가 maxWidth보다 길면 글자 단위로 자른다. `\n`은 강제 줄바꿈.
    - `async renderPage(ctx, page, {width, height, loadImage:(src)=>Promise<CanvasImageSource>, showSafeArea?:boolean})` — 배경색 → 무늬(점: 간격 쪽 폭 4%, 지름 0.35%, `rgba(60,50,40,.18)` / 모눈: 같은 간격 0.15% 선) → 테두리 선(`frameLine`, 안전선 위치 5mm, 선 두께 쪽 폭 0.4%) → 쪽 번호(내용 쪽 2–7만, 왼쪽 위 안전선 안, Nanum Pen Script 쪽 높이 7%, 아래 밑줄) → 요소(z 오름차순) → 제목(Nanum Pen Script 쪽 높이 6%, `titleBox` 위치·폭에 가운데 정렬, 글자 폭+여백만큼 뒤에 `HIGHLIGHTS[titleHighlight]` 70% 불투명 띠를 글자 아래 절반 높이로, 맨 위 레이어) → 요소를 z 오름차순으로 `translate(중심) → rotate → drawImage/텍스트`. 사진은 `object-fit: cover`처럼 잘라 그리고, `frame:'polaroid'`면 요소 상자 전체를 흰 틀(그림자 `rgba(0,0,0,.15)`)로 채우고 사진은 위·좌·우 4%, 아래 16% 안쪽에 그린다. 텍스트 정렬은 `style.align`, 텍스트는 `Nanum Pen Script`, `style.size × height` px, 줄간격 1.25, `wrapText`로 `w × width` 안에서 줄바꿈. 쪽 밖은 클립.
- 화면 편집기도 이 함수로 썸네일을 그리고, 편집 중 DOM 표시는 같은 규칙(제목 위치·글꼴·줄간격)을 CSS로 따른다.

- [ ] **Step 1: 실패하는 테스트** (가짜 ctx가 호출을 기록, `measure = s => s.length*10`):
  - `wrapText splits on spaces`: `('파도 소리가 들리는 골목', 60)` → 각 줄 길이 ≤ 6글자.
