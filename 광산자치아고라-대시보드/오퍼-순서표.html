오퍼는 진행자 멘트를 듣고 버튼을 누릅니다

대형 스크린은 관제 패널이 정한 단계를 따라갑니다. 오퍼는 관제 노트북 한 대에서 버튼을 누르고, 같은 화면의 스크린 미리보기로 결과를 확인합니다. 두 명이면 한 명은 단계·투표·공감·구호, 한 명은 기록 현황·AI 검수를 맡아요.

  • 스크린 PC: 대형 스크린 주소 열기 → 화면 두 번 클릭해 전체화면 → 오른쪽 위 빨간 LIVE 확인. 절전·화면보호기·알림 끄기

2관제 패널에서 늘 볼 곳

🖥 스크린 미리보기 (왼쪽 위)

  • 대형 스크린과 같은 화면. 버튼을 누른 뒤 여기서 바뀌었는지 확인
  • 위쪽 「마지막 변경 hh:mm」이 방금 시각이면 서버에 반영된 것
  • 「서버에 보내는 중…」이 오래가면 Wi‑Fi 확인

📋 테이블 기록 현황

  • 테이블마다 ①·②·③·④·⑤ 칸 수. 0이 오래가는 테이블은 기록자에게 가 보기
  • ③ 칸이 0이면 선정 과제가 비어 있음(동점 등) → 기록자가 직접 적는 중인지 확인
  • ✨ 메모가 뜨면 AI 문장을 고쳐 다시 저장

🗳 ③ 테이블별 휴대폰 투표

  • 테이블별 투표 인원과 1위가 실시간으로 보여요
  • 테이블 퍼실이 「투표 완료」를 누르면 띵 소리 + 알림, T칩이 초록으로. 13/13이면 진행자에게 마감 신호
  • 「투표 마치기」 1분 뒤 각 문서 ③ 탭에 선정 과제(1위)·투표 결과가 자동으로 들어가요
  • 동점·0표 테이블은 자동으로 안 들어가요 → 기록자가 직접

♥ ⑦ 공감 · 응원

  • 공감 카드 목록과 카드별 ♥ 수, 참여 기기 수
  • 잘못된 카드는 눌러서 빼기(☐) — 화면에서 바로 빠져요
  • 대형 화면에는 숫자 없이 하트만 떠요
⚠️ 빨간 버튼(투표 초기화 · 공감 초기화 · 시뮬레이션 기록 지우기)은 행사 중 누르지 않습니다. 눌러도 직전 결과는 관제 시트 log에 남지만, 화면과 집계는 비워져요.
