관제반(1~2명)은 대형 스크린의 단계를 넘기고, AI 요약을 검수하고, 우선순위 투표를 열고 닫습니다. 두 명이면 한 명은 단계·투표, 한 명은 기록 현황 확인과 AI 요약 검수를 맡으면 좋습니다.

1주소와 준비물

화면어디서주소 (witconlab.github.io/witconlab/광산자치아고라-대시보드/ 뒤에)
대형 스크린스크린 연결 PC(아무것도 안 붙임)
관제 패널관제 노트북control.html
투표 페이지참가자 휴대폰vote.html (스크린·안내문 QR)

  • 준비물: 관제 노트북 · 스크린 연결 PC(HDMI) · 충전기 · 테더링용 휴대폰 · 인쇄 안내문(테이블마다 참가자용 1장)
  • 관제 비밀번호 = Apps Script 편집기 → ⚙ 프로젝트 설정 → 스크립트 속성의 ADMIN_KEY 값. 관제반만 알고, 메신저 단체방에 올리지 않습니다.

2행사 전날까지

  • 관제 스프레드시트 tables 시트에서 테이블별 분야·동·대상 공간이 실제 배치와 같은지 확인
  • E열의 문서 링크 12개를 기록자에게 편집 가능으로 공유하고 각자 전달
  • 리허설: 기록자 몇 명과 휴대폰 여러 대로 실제 모드에서 처음부터 구호까지 한 번

3행사 당일 오전 (13:00 전)

  1. 리허설 기록 지우기: Apps Script 편집기에서 resetForEvent 실행. 문서 12개가 양식만 남고, 요약·수동 발언·투표·화면 상태가 비워집니다. 행사 시작 뒤에는 절대 실행하지 않습니다.
  2. 스크린 PC: 대형 스크린 주소를 열고 화면을 두 번 클릭해 전체화면. 오른쪽 위 빨간 LIVE 확인. 절전·화면보호기 끄기.
  3. 관제 노트북: 관제 패널을 열고 연결 설정에 비밀번호 입력 → 저장 후 새로고침.
  4. 비밀번호 확인: 참석 등록을 눌러 스크린이 대기 화면이 되고, 위쪽에 빨간 경고 줄이 없으면 정상.
  5. 대기 화면의 기록 12/12가 모두 초록인지 확인. 빠진 번호는 그 테이블 문서 공유·링크 확인.
  6. 휴대폰 한 대로 안내문 QR을 열어 "아직 투표가 열리지 않았어요"가 보이는지 확인.

빨간 경고 줄 "관제 비밀번호가 맞지 않아 화면이 바뀌지 않았어요"가 뜨면 버튼이 하나도 반영되지 않은 것입니다. 비밀번호 다시 입력을 눌러 고치세요. 버튼을 누르면 위쪽에 "서버에 보내는 중…"이 잠깐 보였다가 "마지막 변경 시각"으로 바뀌면 반영된 것입니다.

5AI 요약 실행과 검수

  1. AI 요약 실행을 누르면 "정리하는 중… 보통 1~3분"이 뜹니다. 그동안 다른 버튼은 그대로 써도 됩니다. (11/6 시험: 40초~약 3분)
  2. 끝나면 오른쪽 AI 요약 · 검수 칸이 채워지고 위에 "Gemini (모델 이름)"이 표시됩니다. 이 결과는 바로 결과 화면에 쓰입니다.
  3. 15:25~15:30 사이에 테이블별 칸을 훑어보고 어색한 문장, 기록에 없는 내용, 개인정보를 고친 뒤 검수 내용 저장. 저장하면 스크린에 바로 반영됩니다.
  4. 실패하거나 3분이 넘으면: 1차(15:15) 결과를 그대로 쓰거나, 실패 알림 뒤 나오는 "태그로 대신 정리할까요?"에 확인 → 기록자의 [실천]·[협력] 줄로 즉시 정리됩니다.

AI 요약을 다시 실행하면 그전에 검수·저장한 내용도 새 결과로 바뀝니다. 그래서 꼼꼼한 검수는 2차(15:25) 결과를 받은 뒤에 하세요.

6우선순위 투표 운영

  1. 후보 만들기 (테이블당 1개): 테이블마다 AI가 정리한 첫 번째 실천과제가 후보가 됩니다. 2개씩 하려면 테이블당 2개.
  2. 후보 목록에서 줄을 누르면 빼거나 다시 넣을 수 있어요(중복·어색한 후보 정리). 투표를 연 뒤에는 바꿀 수 없습니다.
  3. 1인 선택 수 확인(기본 3개) → 투표 열기. 스크린이 QR과 실시간 순위로 바뀌고, 미리 QR을 열어 둔 휴대폰도 10초쯤 안에 저절로 투표 화면이 됩니다.
  4. 참여 인원이 더 늘지 않으면 진행자와 눈을 맞추고 투표 마감.

투표 초기화는 모든 표를 지웁니다. 리허설 때만 쓰고 행사 중에는 누르지 마세요. (11/6 시험: 150대 동시 투표 150/150, 300대 300/300 정상 저장)

7문제가 생기면

이럴 때이렇게
위쪽에 빨간 경고 줄비밀번호 오류 → 비밀번호 다시 입력. 그 전에 누른 버튼은 반영 안 됨
스크린이 안 바뀌거나 멈춤스크린 PC에서 새로고침(F5 / ⌘R) 후 두 번 클릭해 전체화면. 화면 단계는 서버에 있어 그대로 돌아와요
기록 n/12에 회색 점그 테이블 문서 링크·공유 확인 (tables 시트 E열)
한 테이블 기록이 멈춤테이블 기록 현황에서 마지막 기록 시각 확인 → 기록자에게 가서 확인. 급하면 수동 발언 푸시로 대신 올리기
개인정보 등 잘못 올라감기록자가 문서에서 그 줄을 지움 → 스크린 PC 새로고침. 수동 푸시로 올린 줄이면 관제 시트 manual에서 그 행 삭제 후 새로고침
AI 요약이 3분 넘게 / 실패5번의 4 참고 (1차 결과 사용 또는 태그 정리)
Wi‑Fi 끊김관제 노트북·스크린 PC를 테더링으로. 끊긴 동안 스크린은 마지막 화면 유지
휴대폰에 "투표 시간이 아니에요"투표 열기가 눌렸는지(투표 카드 "진행 중") 확인

8행사가 끝나면

  • 투표 마감이 되어 있는지 확인
  • Apps Script 편집기에서 exportVotes 실행 → votes 시트에 후보별 득표가 기록됩니다
  • summary 시트(검수한 요약)와 기록 문서 12개는 결과 보고 자료로 보관. resetForEvent는 실행하지 않습니다
